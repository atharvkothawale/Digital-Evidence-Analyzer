Local AI Forensic Assistant

Natural language analysis grounded in verified scan data using locally hosted Ollama. Zero cloud telemetry.

🔒
Forensic Evidence Privacy: The AI assistant receives investigation metadata only. Raw file contents are never read or transmitted.
⚙️
Ollama is not running locally. To enable the AI assistant:
  1. Install Ollama from https://ollama.com
  2. Pull model: ollama pull llama3.2
  3. Start daemon: ollama serve
